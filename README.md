# 📈 Marketing Budget Optimizer (Multiple Linear Regression)

## 📌 The Business Problem
A company is struggling to figure out where to allocate its advertising budget. They spend money on TV, Radio, and Newspaper ads, but they don't know which platform actually drives sales. 

My goal in this project was to build a Machine Learning model that can predict exactly how many sales will be generated based on specific ad budgets.

## 🛠️ The Solution
I used Python, Pandas, and Scikit-Learn to build a Multiple Linear Regression model analyzing thousands of data points.

**Key Discoveries:**
* **Radio Ads are highly efficient:** For every $1,000 spent on Radio, the model found it yields an additional 189 units sold.
* **Newspaper Ads are a waste of money:** The model proved that Newspaper spend has virtually zero correlation with an increase in sales.
* **Model Accuracy:** The final model achieved an R-Squared score of 90%, proving it is highly capable of predicting future sales.

## 💻 Tech Stack
